# Music Library documentation

Music Library is a free, open-source music library for the Mac, with a companion app for iPhone and Apple Watch. It
keeps two collections side by side: your **Physical Collection** (the CDs and records on your shelf, each with a label
number) and your **Digital Collection** (your music files, ripped, digitized, imported or bought as downloads). These
pages explain every feature, how it works and how to set it up. For a quick look, see the
[website](https://davidlago.github.io/music-library/) or the [README](../../README.md).
